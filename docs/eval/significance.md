# 显著性怎么读

源码：`src/biomed_ontology/eval/stats.py`（`paired_significance`）。

## 点估计不够

README 上的 +0.006 nDCG 可能来自真实机制，也可能来自 37 条 query 的抖动。配对 bootstrap 回答：

- **差值可能有多大/多小**（95% CI）  
- **在「无效应」零假设下看到这么极端差值的频率**（近似 p）  

## 配对自助在做什么

对每个 query，取两臂的指标差 \(\delta_i\)，对 \(\{\delta_i\}\) 做有放回重采样（默认量级 10k），得到 CI 与双侧 p。

常用对比：`ontology_hybrid − bm25_only`；精排归因：`⑥−⑤`、`⑤−BM25`。

## 读表纪律

| 现象 | 正确解读 |
|---|---|
| 点估计为正，CI 跨 0，p≫0.05 | **方向可记，不得宣称显著提升** |
| 中文大、英文负 | 拆 `by_lang`，不要被 overall 平均骗 |
| 小 n 时巨大正效应 | 扩样本后常缩数量级；以当前 gold 为准 |
| 臂「未运行」 | 该行不参与「达成」，不是 0 |

!!! warning "显著性不是免死金牌"
    不显著 ≠ 机制无用；可能是 gold 太小或方差太大。
    显著 ≠ 可以上线；还要看许可、延迟、失败模式。

## 与 T1 豁免的关系

T1（Recall 相对提升门槛）在点估计翻正但仍远低于门槛、且配对不显著时，应保持**署名豁免**，而不是删目标或调阈值。见 [targets](targets.md)。

数字只在 README；这里只教读法。
